# Docaya artwork generation prompts

The user selected two existing images for the current branding: the **Ask Docaya AI D speech-bubble logo** and the **three-dimensional emerald D folder artwork** for main Docaya identity. This selection reuses the exact existing files without new image generation or image edits.

Both assets were originally generated on **6 September 2026** with the **built-in image-generation tool**. The exact original prompts below are preserved from repository commit `635df65`. The selected AI logo is a transparent 1254 x 1254 PNG; the main Docaya artwork remains its original 1536 x 1024 landscape PNG.

Login shows the full Docaya landscape image. The top-left brand area uses a centre-focused square CSS presentation of the same file; the original pixels remain unchanged. The flat `docaya-mark.png` and all `-v2` assets are archived explorations, not active branding.

See the [brand guide](branding.md) for downloads, previews and usage.

## Ask Docaya AI logo

Saved as [public/brand/ask-docaya-mark.png](../public/brand/ask-docaya-mark.png). Originally generated as a new image without a reference image.

```text
Use case: logo-brand. Generate a final isolated transparent-background logo icon for a UAE document AI assistant. A clean geometric emerald green capital-D-shaped speech bubble with a short lower-left chat tail. Left quarter is a near-black vertical document spine with rounded top-left and bottom-left corners. One small red folded-paper corner is inset near the upper-left of the green area. One large opaque white four-point intelligence sparkle is centred in the green bubble. Only UAE green #007A4D, black #152922, red #CE2031 and white. Minimal enterprise identity, bold solid shapes, flat vector-like edges, a 24-pixel-readable silhouette. No text, no gradients, no shadows, no frame, no texture. The icon occupies 84% of a square canvas. OUTPUT WITH ACTUAL TRANSPARENT ALPHA OUTSIDE THE ICON. The white central sparkle stays opaque white. The external background must be empty transparent pixels, not white and not grey, with no pattern.
```

## Main Docaya identity (welcome illustration)

Saved as [public/brand/docaya-welcome.png](../public/brand/docaya-welcome.png). Originally generated as a new image without a reference image.

```text
Use case: ads-marketing. Asset type: premium welcome illustration for Docaya, a modern UAE document intelligence application. Create a polished landscape 3:2 image on a very pale ivory-white background. At the centre a beautifully crafted minimalist emerald-green document folder/rounded architectural D-shaped portal holds three pristine white document sheets with subtle embossed abstract lines (no readable text). A tiny red folded-corner tab and a slender near-black document spine carry UAE flag colours. A small white four-point AI intelligence glint floats discreetly beside the documents. In the far background only, very subtle ivory architectural silhouettes suggest contemporary UAE civic buildings, an elegant dome and a slender modern tower, without an official seal or emblem. High-end soft 3D product illustration, satin ceramic and paper, clean rounded forms, gentle daylight, soft ambient shadows, restrained emerald green/red/black/white accents. Spacious composition with generous ivory negative space and all subjects fully inside the frame. Sophisticated enterprise technology branding, calm and credible, no people, no text, no labels, no watermarks, no busy circuitry, no national flag cloth, no gold, no oversaturated gradients. The central document-and-folder composition should remain recognisable when displayed at 300px wide.
```
